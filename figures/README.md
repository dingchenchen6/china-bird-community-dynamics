# Figures

Current main-line figures. Earlier v1/v2 figure sets are not included (superseded).

| Directory | Contents |
|---|---|
| `figures_v3/` | Full v3 output: multidiversity time-slice maps, trend maps, beta-diversity panels, species trends, driver plots, MCMC diagnostics |
| `figures_top_journal_20260714_v2/` | Curated top-journal figure set |
| `submission_figure_package_20260714_v3/` | Submission-ready figure package (Fig1–Fig6 + supplement) |

Files are provided as PNG (preview) and PDF (vector, for submission). Filenames carry the run label, so `*_200sp_ar1_spatial*` figures come from the primary spatial model and `*_500sp_ar1_temporal*` from the non-spatial breadth extension.

**Known issue.** Older Faith's PD map panels render largely grey due to incomplete phylogeny matching; use the probability-weighted McTavish PD/MPD panels instead. See `reports/RESEARCH_SYSTEMATIC_AUDIT_20260602.md`.
